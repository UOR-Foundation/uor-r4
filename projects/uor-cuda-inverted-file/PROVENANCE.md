# Provenance

## Source and extraction

This package is an independent extraction and cleanup of UOR-R4's CSR bucketed writer and PTX admission approach. Source commit: `3d39b0c720dbe95693efe8aea93b3873247a7ba1` in `UOR-Foundation/uor-r4`.

Source references:

- `crates/uor-r4-discrete/src/bucket_source.rs` — CSR build, incremental update, bucket and full-scan writer evaluation.
- `crates/uor-r4-discrete/build.rs` — ahead-of-time compilation, PTX instruction and exact-entry admission, cubin assembly.
- `crates/uor-r4-core/src/spiralcore_operator.rs` and the discrete build's `geometry_source()` — fixed 16-root codebook provenance.
- `docs/labs/m1-faster-writer/README.md` — historical, hardware-specific qualification evidence for the original implementation. No historical performance result is attributed to this new package.

## Independence

The public package does not include or require the UOR-R4 model, `s[]` ABI, routes, gates, traces, UORLUT01, D11 exporter, model checkpoints, corpus, or objective implementation. It uses a fixed 16-vector codebook and a 256-cell inverted-file index with exact integer distance and tie rules.

No NVIDIA sample source code is copied. No CUDA SDK component, cudarc wrapper, Python package, or external data dependency is redistributed. The CUDA Driver API and CUDA Toolkit are build/runtime prerequisites for the optional GPU path only.

## Evidence boundary

Only results generated by this package's own tests belong in `RESULTS.md` and `docs/labs/uor-cuda-inverted-file/`. Earlier UOR-R4 records are provenance for the extraction, not evidence that this standalone package has passed on any GPU. GPU timing, portability, energy, and cross-library comparisons remain `NOT_RUN` until separately registered and measured.
