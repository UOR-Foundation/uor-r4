# Contextual geometric prediction: target audit before adoption

This is a proposed training auxiliary, not a completed JEPA language model.
The immediate experiment remains the matched phase-balanced native token loss.
The owner approved keeping contextual JEPA, signed spinor/H4 state and
SpiralCore retained-frame transport active as the next architectural candidates.

## Existing learning carrier and target construction

The integer `NativeSourceRealizer::context_encoder_parts` exposes the admitted
context tables and exact H4 geometry. `NativeContextState::step` selects actions
from learned token/self/neighbor coefficients and synchronously composes signed
states. It can encode ordinary tokenizer IDs from identity, without selected
records, role annotations or supplied answer-bearing records. The retained state
must be used, not its noninjective root/radius observation or a Hopf projection.

A bounded candidate target retains all lanes at token positions ceil(m/3),
ceil(2m/3),m of a withheld span. Short spans retain duplicate checkpoints
explicitly. This is contextual within the span; an encoder continued from the
student's preceding context is a different target construction and must not be
silently substituted. A target consisting of one polysemous token supplies no
contextual distinction by itself.

Before training, encode predeclared role, negation, name, number, version-order,
source-owner, direction and scope pairs at a pinned frozen checkpoint. Compare
exact endpoints, ordered three-checkpoint tuples and full signed trajectories.
Report token lengths and token multisets. Unequal-length trajectories are never
made equal by truncation or resampling. Exact byte/token identity is an admission
positive control, not evidence that the encoder understood the distinction.
A collision rejects this target for that pair; absence of a collision is only
necessary information-retention evidence, not semantic or language qualification.

## Conditional auxiliary and controls

A training-only shared finite predictor would predict each checkpoint/lane
from causal student state. Target-conditioned costs over all 120 alternative
student roots attach to the existing state-choice credit carrier. Retain native
token/EOS prediction. Freeze the target encoder and detach its outputs; future
tokens, target states and source labels never enter student forward or runtime.
The existing local conditional credit is a declared biased surrogate, not a
joint recurrent posterior or exact derivative of discrete argmax.

Compare token loss alone, correctly paired contextual auxiliary and the same
auxiliary with fixed target shuffles within declared length/task strata. Inspect
actual first-token prediction, source-sensitive contrasts, exact-value outputs
and complete own-prefix replies, as well as auxiliary loss. State occupancy or
a decreased auxiliary loss alone cannot qualify the mechanism. Target collapse,
required-pair collisions and unpredictable nonce targets need separate diagnosis.
A frozen weak teacher does not become informative simply because it is frozen.

Three checkpoints carry at most 3L log2(120) bits for L lanes; endpoint-only state
carries L log2(120). These are upper bounds, not evidence of actual distinctions
or an argument to remove exact addressed occurrence/version memory. The current
512 framed construction rows are not a general grammar or prose curriculum.

## Serving and SpiralCore boundary

Discard the offline target encoder/predictor at export unless a separately
qualified runtime use is needed. This auxiliary adds no served arithmetic or
state when only the existing native operators are exported. Retained-frame
transport is a separate representation/operator arm: preserve signed orientation
and fiber, use exact H4 composition/inverse tables, and compare against the
current relative-H4 operator. A shared rotation is an isometry; it does not
create semantic separation. A causal frame or learned transport must expose a
measured missing distinction and improve predictions.

The first target audit is deterministic and uses the actual frozen native
encoder. It does not adopt the target or initiate a new training campaign.

There are exactly 64 unique input texts. Repeated signatures correspond only

separation from three checkpoints over the endpoint. It does show retention

It does not show a semantic neighborhood, grammar understanding, future

high-entropy encoding can separate strings without supplying a useful teacher.
Equal retained-state targets also do not imply equal complete model outputs:
the token-conditioned address observations are separate.

Decision: keep contextual JEPA available, but do not adopt a three-checkpoint
auxiliary on this result alone. First audit actual reply spans under a frozen
teacher-input convention, distinguishing role, value, reply form and length.
Then a bounded paired versus shuffled-target learning comparison can test
whether the auxiliary improves prediction. Endpoint-only remains the smaller
candidate because no extra preservation benefit from three checkpoints has
been measured here. The active phase-loss fit is a separate causal pilot.
