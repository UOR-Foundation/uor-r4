## What changed

- `m6_exact_arithmetic.rs`: a strict, original-byte-length-bounded parser for one unsigned decimal `+` or `-`, with a 160-byte limit, 10-digit operand bounds and explicit malformed, unsupported-shape, prompt-limit, overflow and subtraction-underflow errors. Original length is measured before trimming, so leading/trailing whitespace cannot bypass the bound. Full-input candidate/operator detection covers signed, leading-dot, operator-only, nested/alternate-grouped and date-prefixed forms, `%`, `^`, `*`, `/`, `×`, `÷`, trailing/incomplete subtraction, and operators at or after byte 160. The early leading-minus helper trims sentence punctuation and rejects `-`, `- 25`, `- 2.5` and `-?` with either leading or trailing padding; bare signed numbers, signed numeric statements, numbered bullets, number-leading dash prose and ordinary dash prose fall through. Valid ISO date/time prefixes including optional seconds/fraction, `Z`, timezone offsets, sentence punctuation, comma tails and ordinary trailing prose fall through; date-prefixed arithmetic remains an error. Subtraction requires whitespace on both sides and a following numeric/arithmetic operand; trailing minus is an explicit error. Oversized operands report the 10-digit bound before parsing. Exact answers call `GeometricArithmeticEngine` and include actual carry/borrow records.
- WASM and browser worker: `exactArithmetic` returns structured JSON. On the supported stack-backed chat path, a handled answer has no model token IDs, no model weights read, zero completion tokens and no `weightsPerToken`, `allocDelta` or `allocEvents` field. Exact turns skip session checkpoints because they do not advance model state, including `/7` turn-memory stacks. The M1 discrete artifact remains next-token-prediction-only and is not presented as a new chat mode. Local/API streaming and final renderers all display `0 model tokens · tool`, without a computed model rate, model stop reason or allocation delta. The original 32-token trajectory, save/restore and network traps remain intact.
- Tauri and OpenAI transport: `native_exact_arithmetic` shares the Rust function. `desktop_openai.js` returns a JSON fallback with `model: uor-chat`, `uor.tool: m6-exact-arithmetic`, empty completion IDs and zero usage; ordinary prompts retain the existing sidecar stream. Unsupported signed, grouped and overlong arithmetic returns explicit errors instead of synthetic generation.
- Conversation history: `apiMessages()` and `loadConversations()` preserve the exact-tool marker. The user prompt and assistant answer remain visible but are removed as one exchange from later OpenAI context, including after restore. This addresses the measured 81- and 212-position failures without increasing context limits or silently truncating ordinary history.
- Worker identity: live loads carry monotonically increasing operation IDs, including discrete responses. The worker uses an internal latest-load token and suppresses stale commits/errors. Every exported page source-load method is wrapped with start-time operation metadata, and the panel's bundled click is captured before its legacy handler, so older source completions cannot override newer source or API selections. API selection also invalidates an already-posted worker load and clears old capabilities. The page ignores stale numeric responses and clears capabilities/model metadata on a new load or current identity failure, disabling the composer. Missing filenames and missing/invalid hashes fail closed in page/adapter tests; the page also fails closed on a missing current load ID, while the typed adapter separately accepts only an identity-valid no-ID response for its single pending operation. Valid-but-wrong 64-character digests and concurrent loads fail closed on the real worker; wrong-digest errors include both full expected and actual values. Unpinned loads require a valid lowercase digest.
- Identity/package checks: staged frontend/WASM/JS compare against current source. Safe bare manifest paths and legacy `src-tauri/runtime/studio/`-prefixed paths are accepted, while absolute/traversal paths fail. Every manifest entry is hash-checked against its staged file and every external packaged `pkg/`/`models.json` resource against the same bytes.
