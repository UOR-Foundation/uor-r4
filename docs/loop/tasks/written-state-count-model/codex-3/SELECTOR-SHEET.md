# [codex] Native occurrence-selector fit for the copy action

References #4063 and the codex-3 copy sheet. The earlier best-pick diagnostic (#3997) consumed FBS read states and fixed ×16 gain. The Q31 updates (#4017) used frozen exported FBS/Q31 window states. Neither has trained parameters with the released 19-table trunk's four-root input ABI. This experiment fits new integer state to those two saved D11 artifacts independently.

**Native transition.** 192 candidates, source lookback d = 1..6 and trailing query offset q = 0..31. For prefix length n, anchor a = n−1−q. For every absolute candidate p from d through a−1, sum the exact coordinate L1 distance across the four E8 root blocks of token[p−d] against token[a]. Select the lowest distance and then smallest p. Empty eligible set yields None. The domain excludes self-comparisons and the logical future of the anchor; there is no value list, marker lookup, segment restriction or access to labels at inference. Each GPU coordinate accumulates one u32 correct-source vote per TRAIN case if its integer inference equals the labelled source occurrence. Freeze the coordinate with largest support, tie lower q then lower d. No-fit (d=1,q=0). A separate swapped fit receives the other occurrence as every TRAIN label, using identical prefixes, budget and grid. Fit once; no tuning thereafter.

**Data design, frozen before fit.** TRAIN comprises four distinct name pairs crossed with two value pairs, two syntactic frames, both entity/value assignments, both fact orders and both asked entities (128). Held-out has two new name pairs and two new value pairs, two new surface frames and the same factorial (64). Neither split includes Ann, Ben, red, blue, fox or kite as an entity or value. The source labels are first IDs of full unique value spans, determined in the literal-role-v2 tokenization, never inferred from matching a single partial token. The held-out panels assess generalization only on this constructed family. Bind exact input and lexical identities and reject duplicate or overlapping prefixes, identical role labels, non-unique spans, special IDs inside body, or contexts beyond 192. The separate previously fixed 16-case panel reaches inference as an array of records containing only prefix; reject extra fields. The selector never receives its asked/other positions, expected IDs or group names.

**Replay, primary endpoint and decisions.** Both immutable released artifact hashes/seed-bound tokenizers are fixed in the main sheet. One CPU finite oracle and the research GPU compare L1 argmins including exact ties, empty eligibility and a planted source displacement. Demonstrate at least one TRAIN label swap moving the score inventory on the finite control. Freeze state as JSON with artifact hash, TRAIN hash, arm, selected d/q, and 192 raw u32 counters. The state identity is SHA256 of its exact file bytes. Reload state; compare every GPU-inferred source to the ordinary integer serving operator on every held-out and prediction-only prefix, before grading. The primary descriptive measurement is exact first-source hits per 64 held-out cases, for all three arms at both seed artifacts. A useful selector here requires the trained rule to beat both controls on asked-source count at both seeds and to switch sources correctly when the requested entity switches within a matched pair. Report both individual count and both-correct pair count. Absence of gain, constant/identical choices, or failed transfer is preserved as a negative for this small rule family. A FIT or parity failure is instrument failure, not a learned-selector result. No model or milestone promotion. Holdout labels grade after fitting; do not alter d/q, generate more data or retune after transfer. On the existing 16 prompts, run all three frozen arms as separate prediction files; only the trained arm drives the requested new writer contrast.
