## What did not work

The first 5090 reproduced the frozen C128 count bytes and every planted optimizer word, but the loaded machine code used data-dependent floating reciprocals for integer division. A predicate-aware scan of the next build also found 11 instructions introduced when the compiler optimized a variable-stride histogram loop. Those builds failed the native instruction gate. Wick retains the binaries and disassembly. The repaired build uses explicit integer quotients and the histogram's original fixed launch geometry. Its six application images passed the disassembly check. The remaining half-precision opcode occurrences have zero-register multiplicands and materialize fixed constants. ## What changed

The count writer streams matching raw and adjusted partitions by original context, preserves per-order spectra and serializes a complete query-independent table. Reserved TRAIN supplies the full bucket-major Q32 vector for the registered session-copy expert, which selects the most recent minimum-distance pair of original token codes. The ordinary text client loads the registered D11, tokenizer and a package containing the compact count file, original fit manifest and exact weight bytes. Given a causal prefix, it ranks original IDs 1–4095 using the shared count interpolator and fitted mixture. The lowest ID wins a mass tie. The optional decision trace hashes all 4,095 mass words and records the copy predecessor and successor. Timing a plain reply omits trace collection. The 1%, 10% and 100% historical C censuses imply 2,229,740,835, 18,438,591,940 and 148,096,362,864 bytes respectively for complete tables in this format. Only the first number has a physical deployed table from this run. At full dose, orders zero through three alone cost 3,058,504,360 table-section bytes. A candidate under four decimal GB can therefore preserve those orders and has about 855 MB for higher orders after charging the original trunk, headers and weights. The concrete next comparison is to retain whole higher-order contexts by a preregistered training-data criterion, charge every retained key and index, then refit on R using exactly those deployed lookups. The format will need to identify its pruning policy and which spectra determine its discounts. Compare the frozen candidate on DEV-tune before any registered sealed test.
