## Decision

Phase 0A exercised each declared non-H4 channel independently. No available
channel simultaneously retained earlier order, distinguished candidates,
formed pure construction classes, and transferred the construction rule to a
sealed validation query. The predeclared hard stop therefore fired before any
omnibus combination, scalar search, selector compilation, validation
selection, Gate 0 decode, or sentence qualification.

The result localizes a bounded representation defect. Every eligible non-H4,
non-digest channel key has zero earlier-order sensitivity on the frozen matched
population, and no real non-digest transported-path field is exposed. Pairing
an aliased history state with a distinct static candidate state separates the
candidates but cannot recover the discarded history order. The separate H4
commitment and #967 ordered-H4 state remain order-sensitive structural state;
this result neither erases nor invalidates them.

## Phase 0A metric contract

- Earlier-order sensitivity counts unequal exact history-channel keys over all
  15 pairs of the six matched histories.
- Candidate sensitivity counts histories whose `ll` and `rr` exact keys
  differ, over six histories.
- Same-candidate change counts unequal exact keys over the 30 within-candidate
  history pairs: 15 pairs for each of two candidates.
- Construction purity requires every exact class seen in construction to
  contain only `SELECT` or only `REJECT` outcomes.
- Sealed-validation coverage counts validation decisions whose exact class was
  already present in construction.
- The no-class-splitting oracle ceiling sums the majority validation outcome in
  each exact class without splitting that class.
- Construction-transfer decision ceiling counts validation decisions matched
  by a pure construction-class outcome. Query ceiling additionally requires
  both candidate outcomes to transfer with exactly one `SELECT`.
